# 飯糰小店 SVG 視覺參考圖生成提示詞

> 最終人物動畫使用透明 PNG 影格，不使用員工 SVG。主舞台實際動作與檔名相反：`anim-walk-01.png`–`anim-walk-08.png` 是手持飯糰影格，`anim-carry-01.png`–`anim-carry-08.png` 是空手向右離場影格。完整整合規則見 [`WORKER-PNG-ANIMATION.md`](WORKER-PNG-ANIMATION.md)。

這份文件是為 `product/src/img/` 與 `product/src/lottery/storyboard/` 的 SVG 重繪準備的圖像生成提示詞。生成的圖片是**視覺參考稿**，用來確認造型、配色、構圖和動作，不是最終 SVG，也不應直接把點陣圖當作 SVG 替代品。

## 使用方式

1. 先把「共用視覺規範」貼到每一個生成任務的最前面，再接上對應素材或關鍵幀提示詞。
2. 角色／物件設定圖盡量要求透明背景、正面或指定角度、單一主體；分鏡圖則使用 16:9 橫向構圖。
3. 角色和物件最好以同一模型、同一 seed 或參考圖功能生成。先定稿一張員工和一顆飯糰，再將該圖作為後續一致性參考。
4. 生成圖上的中文字、姓名、品牌、標籤、按鈕字樣都留白，最後由 HTML/SVG 以真正文字排版。姓名尤其必須留給程式後製，不能烘焙進圖片。
5. 素材設定圖可使用高解析度 PNG；重繪 SVG 時，以圖像中的外輪廓、色塊、比例與明暗作參考，不必照抄點陣細節。

## 共用視覺規範（每個提示詞都先貼這段）

> 為一個溫暖、精緻、帶有輕微日系昭和喫茶店氣質的公司年度聚餐抽獎活動，繪製視覺設計參考圖。整體是親切的 2D 手繪感向量插畫：外輪廓使用清晰的焦糖棕線條，色面柔和、帶少量細緻明暗與紙感，不要照片寫實或厚重材質。造型像高品質品牌角色設定圖，比例圓潤、表情簡潔。色彩以奶油米白、焦糖木棕、深青綠為基底，珊瑚橘、琥珀金、靛藍、梅紫作制服點綴。場景明亮、溫暖、整潔，避免裝飾搶走主體。請維持同一角色、飯糰、店鋪和貨架在不同畫面中的形狀與比例一致。除非該提示詞另外指定，不要加入任何文字、字母、數字、Logo、水印或標籤；得獎姓名留給 SVG 文字層後製。

### 共用負面提示詞

> 不要照片寫實、3D 渲染、塑膠公仔高光、厚重油畫筆觸、粗糙水彩、複雜漸層、過多細節、雜亂背景、透視變形、模糊輪廓、裁切主體、額外手指或肢體、重複人物、錯誤日文／中文、亂碼、假字、英文裝飾字、浮水印、簽名、商標。飯糰一律不畫臉、不畫眼睛、不畫嘴、不畫腮紅；得獎姓名不可直接畫入圖片。

## 建議全域造型設定

- **主舞台比例：** 1920×1080、16:9 橫向。店鋪正面、橫向延展，員工沿畫面底部由左往右移動。
- **材質語彙：** 平滑向量色塊，外輪廓清晰；少量柔和投影，避免細碎紋理。
- **背景：** 奶油米色到暖米褐的柔和色域；深青綠用在店招／制服；暖木色用在店體和貨架。
- **商品規則：** 待機貨架飯糰造型一致且無姓名；抽獎落下的飯糰也無姓名；只在最後揭曉狀態由 SVG 文字把姓名置中疊在得獎飯糰上。
- **空間規則：** 員工在貨架前方下方的步行帶；員工不要遮住主要貨架商品。中央屋頂留出出貨口位置。不要加入輸送帶、機械手臂或可見換架機器。
- **圖中文字：** 圖像模型不負責文字。店招、狀態標籤、獎項資訊、名字、註解和方向箭頭都由 SVG 後製。
